## 사용법

- 50분 집중 + 10분 휴식을 완료하면 **포크 1개**.
- 포크가 쌓이면 펫이 진화합니다.
- 가장 많이 집중한 시간대(아침·오전·낮·저녁·밤)에 따라 진화 방향이 결정됩니다.
- 3일 연속 집중을 안 하면 펫이 사망합니다.
- 트레이 아이콘 클릭으로 상태창 열기.

총 47번의 포크(약 39시간 집중)로 최종 단계 도달.
